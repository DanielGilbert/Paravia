## Santa Paravia en Fiumaccio
This is the C# conversion of the text-based resource management game "Santa Paravia en Fiumaccio". It was first released in 1978, and received a translation to ANSI-C in 2003. If you are interested in more details of this game, please visit the accompanying blog article on my page:

https://g5t.de/articles/20250709-santa-paravia/
